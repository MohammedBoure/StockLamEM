# Module `ui/widgets/paiement_livraison/`

Espace dédié à l'entrée **Paiement Livraison** de la barre de navigation latérale (`Page 18 : Paiement Livraison`, `nav_paiement_livraison`).

## Fichiers
- `__init__.py` : Exporte `PaiementLivraisonTab`.
- `paiement_livraison_tab.py` : Vue principale `PaiementLivraisonTab` héritant de `BonPaymentsWorkspaceWidget` (`ui/widgets/versement/`) pour gérer les bons `BON_LIVRAISON` avec ajout direct (`+ Paiement`) et modification inline des paiements.
- `README.md` : Documentation de ce répertoire.

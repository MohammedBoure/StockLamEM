# `ui/widgets/appliance_desks` Directory Overview

This directory contains the PySide6 UI desk modules implementing the 5-part Electrical Appliance Store & Multi-Desk Operational Workflow (مكتب الطلبات، مكتب الصندوق Caisse، مكتب الإخراج والمخزن، مصلحة ما بعد البيع SAV، وإدارة الدفعات والأرقام التسلسلية), styled with scoped QSS selectors, proper table header/column proportions, and vector duotone SVG icons.

## Files in this Directory

- **`__init__.py`**: Package initializer exporting all desk widgets and modal dialogs.
- **`appliance_workflow_tab.py`**: Unified `ApplianceWorkflowTab` hub combining all five operational desks with real-time cross-desk Qt signal synchronization, RBAC tab visibility enforcement, vector duotone SVG tab icons, and Multi-Scanner HID routing.
- **`order_desk_view.py`**: `OrderDeskWidget` featuring top-positioned session tabs (`QTabBar`), movable horizontal splitter (`QSplitter`) with persistent position memory across restarts (`QSettings`), expanded category column width (165px) with full descriptive tooltips, interactive `ColorBadgeWidget` displaying real visual color swatches and tooltips with hex codes, heightened Total TTC action buttons (`Bon Comptant` 44px, `Bon Crédit` and `Bon de Livraison` 40px), universal barcode recognition (across `Products_Master`, batch barcodes, and composite serials) with automatic cart addition, pure theoretical reservations without literal serial registration, sleek tab close button management (hidden for single session, custom styled for multiple sessions), tab right-click context menus, automatic session creation from hardware scanner scans, client autocomplete and quick creation, and visual theme harmonization with `Stock & Magasin` (`#007572`).
- **`quick_client_dialog.py`**: `QuickClientDialog` modal dialog providing instant, in-context customer registration (Name, Phone number, Delivery address, Initial credit limit) directly from the Order Desk without leaving the screen.
- **`cashier_desk_view.py`**: `CashierDeskWidget`, `AdminAuthModal`, and `BonRetourDialog` for Caisse settlement (`Valider Bon Comptant`), Admin-authorized `Bon Crédit`, `Bon de Livraison` advance/COD collection, customer account deposits (`Versement`), and `Bon de Retour` issuing virtual wallet credit (`Versement Virtuel`) with zero physical Caisse liquidity impact.
- **`dispatch_desk_view.py`**: `DispatchDeskWidget` for the Warehouse/Dispatch Desk (مكتب إخراج السلع), verifying literal product barcodes and unique serial numbers (`N° de Série`) and generating `Bon de Sortie` logistical vouchers.
- **`sav_kanban_view.py`**: `SAVKanbanWidget`, `SAVReceptionDialog`, and `IrreparableDefectModal` implementing the 4-stage SAV / Réparation state machine (`SAV_RECEIVED` -> `SAV_SENT_TO_TECH` -> `SAV_RETURNED_FROM_TECH` -> `SAV_CLOSED_DELIVERED`) and the irreparable compensation mechanism (`Versement Virtuel` into `Client_Wallets`).
- **`serial_batch_view.py`**: `SerialBatchRegistryWidget` (Desk "5. Traçabilité & Lots") featuring a dual-tab architecture: (1) `Référentiel Lots & Produits` displaying the Centralized Inbound Policy Banner (locking direct batch/product creations and restricting arrivals strictly to `Achats & Entrées` and `Stock & Magasin`), real-time `SerialAuditCard` for instantaneous barcode/serial number verification and status inspection, and the live catalog comparing Physical Stock vs Theoretical Reserved vs Available for Sale; (2) `Journal de Traçabilité & Mouvements` providing a live audit trail of all warehouse physical movements (`Sorties Magasin / Bon de Sortie`, `Réceptions Lots`, `Retours`) connected directly to `Stock_Movement_Log`.

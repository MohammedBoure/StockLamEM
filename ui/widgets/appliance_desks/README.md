# `ui/widgets/appliance_desks` Directory Overview

This directory contains the PySide6 UI desk modules implementing the 4-desk Electrical Appliance Store Operational Workflow (مكتب الطلبات، مكتب الصندوق Caisse، مكتب الإخراج والمخزن، ومصلحة ما بعد البيع SAV), styled with scoped QSS selectors, proper table header/column proportions, and vector duotone SVG icons.

## Files in this Directory

- **`__init__.py`**: Package initializer exporting all desk widgets and modal dialogs.
- **`appliance_workflow_tab.py`**: Unified `ApplianceWorkflowTab` hub combining the four operational desks (Commandes, Caisse, Dispatch, and SAV) with real-time cross-desk Qt signal synchronization, RBAC tab visibility enforcement, vector duotone SVG tab icons, and Multi-Scanner HID routing (the redundant 'Traçabilité & Lots' tab was completely removed per Task #2, as physical traceability is centralized in the left navbar `Traçabilité`).
- **`order_desk_view.py`**: `OrderDeskWidget` featuring:
  - **Vibrant Filter Bar & Dynamic Color Swatches**: Energetic, modern `OrderTopFilterBar` (54px height) featuring a crisp teal gradient background with brand accent bar (`#007572`), dedicated filter header badge with vector icon, icon-badged field labels (Marque, Catégorie, Couleur), antialiased circular color swatch icons (`QIcon`) on every item in `cbo_color`, interactive live `ColorFilterBadge` showing the active color preview dot and hex code with click-to-reset capabilities, instant search clear button (`setClearButtonEnabled(True)`), live reactive catalog counter KPI badge (`lbl_catalog_count_badge`), and automatic synchronization of custom catalog finishes into the filter.
  - **Dedicated Cart 5-Column Table, Visual Color Swatches & Row Remove Button (Task #5)**: Redesigned the Order Desk active session cart table (`cart_table`):
    * **5 Configured Columns**: `Désignation` (responsive with >= 180px minimum clamp), `Couleur` (105px, featuring `ColorBadgeWidget`), `Qté` (80px, `CartQtyStepper`), `Total TTC` (105px, bold), and `Suppr.` (42px, `CartRemoveCellWidget`).
    * **Visual Color Swatch Representation**: The `Couleur` column in the cart now embeds `ColorBadgeWidget` displaying an antialiased circular color swatch (14px diameter, 1.5px border avoiding white-on-white blend) alongside the color name and rich interactive tooltips with hex codes.
    * **Dedicated Remove Button**: Each cart row features a dedicated `CartRemoveCellWidget` housing a centered 26x26 button (`btn_delete`) with vector SVG trash icon (`get_trash_icon(14)`), soft red hover feedback (`#FEE2E2` / `#F87171`), pointing hand cursor, and instant row removal with live total recalculation.
    * **Horizontal Scrolling & Clamp Protection**: Enabled smooth `ScrollPerPixel` horizontal scrolling (`Qt.ScrollBarAsNeeded`), dynamic expansion when cart panel has surplus space, and minimum 180px clamping (`_adjust_cart_column_widths` and `_on_cart_header_section_resized`) preventing product name or control clipping when the cart panel or splitter is narrowed.
  - **Dedicated 3-Tier Price Column & Borderless Add Action Button (Task #4)**: Separated catalog price display and cart addition into two dedicated columns (8 columns total):
    * **Column 6 (`Prix TTC`, 150px)**: Hosted in `ProductPriceWidget`, cleanly displaying active retail price (Prix 1 - Comptoir) in prominent `#007572` teal alongside sub-tier prices (Prix 2 - Demi-Gros and Prix 3 - Grossiste B2B) in subtle `#64748B` slate, equipped with rich HTML tooltips detailing all wholesale margins. Supports dynamic client tier price selection (`Prix_1` / `Prix_2` / `Prix_3`) upon cart addition.
    * **Column 7 (`Ajout`, 55px)**: Hosted in `AddActionCellWidget`, featuring a framed cell slot (`QFrame#AddActionSlot`, 40x32px, border-radius 6px) containing a borderless, padding-optimized `+` button (`QPushButton#BtnPlusOnly`, 30px height, `border: none; background: transparent;`) with hand cursor and soft hover highlight, ensuring zero bottom vertical clipping inside the 48px row (leaving 16px vertical breathing room). Out-of-stock items feature a disabled state (`—`) without vertical clipping.
  - **Dynamic Responsive Column Sizing & Anti-Clipping**: Clamped minimum width (>= 280px) for `Désignation Produit` (column 1) preventing text truncation when the catalog table or window is narrowed, interactive column resize mode with automated surplus space expansion on wide screens, minimum 260px clamp protection against accidental header drag collapsing, smooth pixel-by-pixel scrolling (`ScrollPerPixel`) with styled custom horizontal and vertical scrollbars (`QScrollBar:horizontal` and `QScrollBar:vertical`).
  - **Ultra-compact Low-profile Session Bar**: `SessionTabsBar` (26px height, tabs 22px height) with properly positioned, high-contrast close buttons (`×`, 16x16) on all sessions (white on active teal tab, slate on inactive tab, soft red hover) that close sessions or reset single sessions without crashing, and compact `+ Nouvelle Session` button (22px height).
  - **De-nested Clean Panels & Lazy Loading**: Seamless panels eliminating stacked containers, catalog lazy loading (35-item batches on demand and on scroll) with dynamic item counters, fix for double overlapping text in the Color column (pure `ColorBadgeWidget` rendering).
  - **Ergonomic Buttons & Splitter**: Heightened and widened Action buttons (30px height, 195px column) with crisp white shopping cart icons, complete removal of obsolete "Vente Théorique" and "Isolation HID Active" texts, movable horizontal splitter (`QSplitter`) with persistent position memory across restarts (`QSettings`), expanded category column width (160px) with full descriptive tooltips, interactive `ColorBadgeWidget` displaying real visual color swatches and tooltips with hex codes, heightened Total TTC action buttons (`Bon Comptant` 44px, `Bon Crédit` and `Bon de Livraison` 40px), full-width client search combobox (36px height) with separate header row for `+ Nouveau Client`, universal barcode recognition with automatic cart addition, pure theoretical reservations without literal serial registration, tab right-click context menus, and visual theme harmonization with `Stock & Magasin` (`#007572`).
- **`quick_client_dialog.py`**: `QuickClientDialog` modal dialog providing instant, in-context customer registration (Name, Phone number, Delivery address, Initial credit limit) directly from the Order Desk without leaving the screen.
- **`cashier_desk_view.py`**: `CashierDeskWidget`, `AdminAuthModal`, and `BonRetourDialog` for Caisse settlement (`Valider Bon Comptant`), Admin-authorized `Bon Crédit`, `Bon de Livraison` advance/COD collection, customer account deposits (`Versement`), and `Bon de Retour` issuing virtual wallet credit (`Versement Virtuel`) with zero physical Caisse liquidity impact; featuring heightened validation buttons (`Valider Bon Comptant` 46px, `Autoriser Bon Crédit` 42px, `Valider Bon de Livraison` 42px) and heightened bottom action buttons (`Enregistrer Versement Client` 44px, `Émettre Bon de Retour` 44px, modal dialog buttons 40px) ensuring superior tactile touch/click feedback.
- **`dispatch_desk_view.py`**: `DispatchDeskWidget` for the Warehouse/Dispatch Desk (مكتب إخراج السلع), verifying literal product barcodes and unique serial numbers (`N° de Série`) and generating `Bon de Sortie` logistical vouchers.
- **`sav_kanban_view.py`**: `SAVKanbanWidget`, `SAVReceptionDialog`, and `IrreparableDefectModal` implementing the 4-stage SAV / Réparation state machine (`SAV_RECEIVED` -> `SAV_SENT_TO_TECH` -> `SAV_RETURNED_FROM_TECH` -> `SAV_CLOSED_DELIVERED`) and the irreparable compensation mechanism (`Versement Virtuel` into `Client_Wallets`).
- **`serial_batch_view.py`**: `SerialBatchRegistryWidget` (Desk "5. Traçabilité & Lots") featuring a dual-tab architecture: (1) `Référentiel Lots & Produits` displaying the Centralized Inbound Policy Banner (locking direct batch/product creations and restricting arrivals strictly to `Achats & Entrées` and `Stock & Magasin`), real-time `SerialAuditCard` for instantaneous barcode/serial number verification and status inspection, and the live catalog comparing Physical Stock vs Theoretical Reserved vs Available for Sale; (2) `Journal de Traçabilité & Mouvements` providing a live audit trail of all warehouse physical movements (`Sorties Magasin / Bon de Sortie`, `Réceptions Lots`, `Retours`) connected directly to `Stock_Movement_Log`.

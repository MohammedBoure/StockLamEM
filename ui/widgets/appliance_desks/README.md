# `ui/widgets/appliance_desks` Directory Overview

This directory contains the PySide6 UI desk modules implementing the 4-desk Electrical Appliance Store Operational Workflow (مكتب الطلبات، مكتب الصندوق Caisse، مكتب الإخراج والمخزن، ومصلحة ما بعد البيع SAV), styled with scoped QSS selectors, proper table header/column proportions, and vector duotone SVG icons.

## Files in this Directory

- **`__init__.py`**: Package initializer exporting all desk widgets, modal dialogs, and the standalone `SAVWorkspaceTab`.
- **`appliance_workflow_tab.py`**: Unified `ApplianceWorkflowTab` hub combining the operational desks (Commandes, Caisse, Dispatch; SAV is decoupled into its own navbar page by default with `include_sav=False`) with real-time cross-desk Qt signal synchronization, RBAC tab visibility enforcement, vector duotone SVG tab icons, and Multi-Scanner HID routing (the redundant 'Traçabilité & Lots' tab was completely removed per Task #2, as physical traceability is centralized in the left navbar `Traçabilité`).
- **`sav_workspace_view.py`**: Dedicated Multi-Tab Service Après-Vente (SAV) & Réparations Workspace (`SAVWorkspaceTab`, Task #9) completely decoupled from the sales operational desks into its own independent Left Navigation Bar button (`Page 15`, `nav_sav` / `wrench_sav` icon):
  - **Dedicated Status Tabs**: Separates every repair ticket lifecycle state into its own full-screen, dedicated tab:
    * `Tab 0`: `📋 Toutes les Demandes` (Global overview of all tickets with live counter badge)
    * `Tab 1`: `📥 1. Réception Client (Dépôt)` (`SAV_RECEIVED`)
    * `Tab 2`: `🔧 2. En Atelier / Réparateur` (`SAV_SENT_TO_TECH`)
    * `Tab 3`: `✅ 3. Prêt pour Restitution` (`SAV_RETURNED_FROM_TECH`)
    * `Tab 4`: `📦 4. Clôturés & Livrés` (`SAV_CLOSED_DELIVERED`)
    * `Tab 5`: `⚠️ 5. Appareils Irréparables` (`IRREPARABLE_COMPENSATED` / virtual wallet credit)
  - **Full-Width Responsive Tables**: Clean 10-column table layout with anti-truncation column sizing, smooth `ScrollPerPixel` horizontal/vertical scrolling, visual warranty status badges, technician assignment, customer symptoms, and stage-specific action buttons (`Envoi Atelier`, `Retour Réparation`, `Remise Client & Clôture`, `Déclarer Irréparable`, `Imprimer Bon`).
  - **Global KPI Summary Bar**: Top live status badges indicating total tickets, intake depot count, repairer workshop count, ready for return count, closed count, and irreparable count.
  - **Instant Multi-Field Search**: Real-time filtering across Ticket number, Bon barcode, Serial number, Product, Client, and Reported defect.

    * **Brand Column Expansion (110px)**: Expanded column 0 (`Marque`) from 80px to 110px, completely resolving brand text truncation with ellipsis (e.g. `KBIOCH...` now renders cleanly as full `KBIOCHIMIE`, `ELECTROLUX`, `SCHNEIDER`).
    * **Action Column & Centered Framed Slot (65px)**: Expanded column 7 (`Ajout`) from 55px to 65px and re-engineered `AddActionCellWidget` with an ergonomically sized framed slot (`QFrame#AddActionSlot`, 38x30px, `1.5px solid #CED4DA; border-radius: 4px;`) and centered borderless button (`QPushButton#BtnPlusOnly`, 34x26px), guaranteeing all 4 borders (top, bottom, left, right) remain crisp, intact, and never clipped by the vertical scrollbar.
    * **Price Dropdown Column Anti-Cramping (155px)**: Sized column 6 (`Prix TTC`) to 155px and refined `ProductPriceWidget` (`28px` height, `1.5px solid #CED4DA; border-radius: 4px; padding: 2px 8px;`), eliminating text and chevron truncation for multi-digit amounts.
    * **Pinned Bottom Summary Bar & Scroll Area Stabilization**: Set outer scroll area vertical scrollbar policy to `ScrollBarAlwaysOff`, ensuring the bottom information bar (`catalog_bottom_bar`) remains pinned, visible, and never pushed off the screen viewport, while data tables scroll internally with smooth pixel-by-pixel scrolling.
    * **Splitter Non-Collapsible Panel Protection**: Clamped splitter minimum panel sizes (`catalog_panel >= 550px`, `cart_panel >= 320px`, `setChildrenCollapsible(False)`), preventing either the catalog or cart from collapsing into a squeezed strip.

  - **Default Available-Only Filter (Task #6)**: Introduced a prominent, ergonomic availability toggle filter (`chk_available_only`, aliased as `btn_available_only`) in `OrderTopFilterBar`:

- **`sav_kanban_view.py`**: `SAVKanbanWidget`, `SAVReceptionDialog`, and `IrreparableDefectModal` implementing the 4-stage SAV / Réparation state machine (`SAV_RECEIVED` -> `SAV_SENT_TO_TECH` -> `SAV_RETURNED_FROM_TECH` -> `SAV_CLOSED_DELIVERED`) and the irreparable compensation mechanism (`Versement Virtuel` into `Client_Wallets`).
- **`serial_batch_view.py`**: `SerialBatchRegistryWidget` (Desk "5. Traçabilité & Lots") featuring a dual-tab architecture: (1) `Référentiel Lots & Produits` displaying the Centralized Inbound Policy Banner (locking direct batch/product creations and restricting arrivals strictly to `Achats & Entrées` and `Stock & Magasin`), real-time `SerialAuditCard` for instantaneous barcode/serial number verification and status inspection, and the live catalog comparing Physical Stock vs Theoretical Reserved vs Available for Sale; (2) `Journal de Traçabilité & Mouvements` providing a live audit trail of all warehouse physical movements (`Sorties Magasin / Bon de Sortie`, `Réceptions Lots`, `Retours`) connected directly to `Stock_Movement_Log`.

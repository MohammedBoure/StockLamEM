# UI Widgets — Utilisateurs (`ui/widgets/users`)

Dedicated UI module for the **Utilisateurs** navigation bar workspace (`Page 5`, `tab_users`).

## Files and Purpose

- **`__init__.py`**: Package initializer exporting `UserManagementTab`, `UserDialog`, and `SYSTEM_PERMISSIONS`.
- **`user_management_tab.py`**: User account management interface (`UserManagementTab`) and role/permission matrix dialog (`UserDialog`) covering all modules including `Bureaux Opérationnels` (`10. BUREAUX_WORKFLOW`) and `Service Après-Vente` (`11. SAV_WORKSPACE`).

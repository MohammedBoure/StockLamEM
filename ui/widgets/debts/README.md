# UI Widgets — Créances Clients (`ui/widgets/debts`)

Dedicated UI module for the **Créances Clients** navigation bar workspace (`Page 13`, `nav_debts`).

## Files and Purpose

- **`__init__.py`**: Package initializer exporting `DebtsManagementTab` and `GlobalPaymentDialog`.
- **`debts_management_tab.py`**: Client receivables and debt tracking workspace (`DebtsManagementTab`), debtor aging summary, unpaid invoices table, FIFO global payment allocation (`GlobalPaymentDialog`), CSV export, and client statement integration.

# Reference Modules Index (`pyside6-ui`)

Load only the module(s) relevant to the active PySide6 screen or component:

- **`design-system-and-qss.md`**: Centralized Light/Dark tokens, QSS selector architecture, Fusion/HiDPI setup, selector leakage prevention, and structural primitives (`PageHeader`, `CardFrame`, `StatCard`, `StatusBadge`).
- **`navigation-and-shell.md`**: `QMainWindow` shell patterns (sidebar + `QStackedWidget`, tabs, `QDockWidget`, toolbars), `QSplitter` workspaces, `QSettings` window persistence, and canonical action placement.
- **`data-tables-and-filters.md`**: High-performance `QTableView` / `QTreeView` Model/View patterns, column sizing, locale-aware formatting, debounced search, segmented filter pills, and empty/loading states.
- **`forms-dialogs-and-feedback.md`**: Three-zone `QDialog` modals, responsive 2-column forms, inline validation, master-detail drawers, safe destructive confirmations, and non-blocking overlay toasts.
- **`accessibility-i18n-and-async.md`**: Keyboard-first focus lifecycle, accessibility attributes, internationalization & `Qt.RightToLeft` (RTL) support, and `QThreadPool` async responsiveness.
